LIMITS, DECLARED UP FRONT

What these results do not promise.

Scheme rules stay in force

Minimum age {{ rules.age }} · ₹250/month · {{ rules.sla }}-day deemed approval. The configured application deadline is {{ rules.deadline }}.

Current application window: {{ 'OPEN' if rules.window_open else 'CLOSED' }}. After closing, new submissions fail; follow-up and officer decisions continue. Historical passing results do not override the deadline.

Free hosting is a compromise

Render sleeps; the measured reconnect took about 26 seconds. Allow 60–120 seconds and retries in external clients. Free quotas, Supabase inactivity pausing and best-effort GitHub scheduling remain operational constraints.

Simulation and privacy

SMS is simulated and requires authorized assessor access. The dashboard exposes no OTPs, passwords, tokens, bank details, private PDF links, or real citizen records. Application file logs remain ephemeral; private orphan uploads need retention management.

Evidence has a boundary

No Claude Code run, local-language conversation, field usability study, full-duration expiry wait, or 30-day uptime observation is claimed. This is a tested prototype with one configured departmental account, not a complete production security audit.
